I'm a CS master's student at the University of Tulsa, finishing in May 2027. Most of my work is with AI agents, both using them and building the scaffolding that makes them useful. I'm drawn to problems that stay broken, so I build the tool, and often the tool that builds the tool.

**What I'm building**

- **[HyprMac](https://github.com/zacharytgray/HyprMac)**. A keyboard-driven tiling window manager for macOS. Caps Lock becomes a Hypr key and windows stop being your problem. It has 100+ stars, PRs from outside contributors, and a Homebrew tap. [hyprmac.app](https://hyprmac.app)
- **[jev-context-filter-harness](https://github.com/zacharytgray/jev-context-filter-harness)**. The code and every run record behind my paper submitted to AAMAS 2027. A small classifier screens what an agent's tools hand back before the agent reads it. It cut prompt tokens by up to 70%, and on AgentDojo it dropped Gemma's attack success from 259 of 949 to 1 of 949.
- **[jev-claude-plugin](https://github.com/zacharytgray/jev-claude-plugin)**. The same idea as a Claude Code plugin, wrapped around the agent's tool calls.
- **[Daybook](https://github.com/zacharytgray/daybook)**. A morning brief and a live day board for people who work with AI agents. Python standard library, no accounts.
- **[self.kb-template](https://github.com/zacharytgray/self.kb-template)**. A knowledge base of yourself. An agent interviews you, and your resume, site and posts all draw from the one source.
- **[OllamaHelperModule](https://github.com/zacharytgray/OllamaHelperModule)**. A small Python agent for local Ollama models, with memory, system prompts and tool calling.

**Teaching.** I built CS-4103 Fundamentals of Machine Learning at TU and TA it.
